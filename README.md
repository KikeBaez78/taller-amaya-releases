# Taller Amaya — Canal Oficial de Actualizaciones OTA (Over The Air)

Repositorio exclusivo de distribución de actualizaciones oficiales para el Sistema de Control Automotriz de **Taller Amaya**.

## Estructura
- `version.json`: Manifiesto público de versión consultado por el panel del taller.
- `builds/`: Paquetes de actualización compilados descargados automáticamente al ingresar el PIN de autorización.
